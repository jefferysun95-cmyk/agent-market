# 自主注册本地验证记录

日期：2026-11-09。开发预览，未发布/部署；线上仍是 alpha.4 邀请制。测试使用临时 SQLite、合成地址/验证码/平台密钥及内存发信器，没有接入真实 SMTP、Gmail 或生产身份/订单。

## 已实现与证据

- `registration.py`：共享数据库上的公开 start/finish、验证码哈希/过期/错误次数、注册幂等、受限交换重放、显式重新验证恢复、运营者撤销保护、注册限流及身份槽位。
- `server.py` / `app.py`：标准库 HTTP 与 ASGI 共用上述服务；未启用时返回 503，health 显示关闭。交易继续使用同一 Store，新增账户按验证地址共享建任务/报价配额，旧身份保持兼容。
- CLI `register start/finish`：请求前持久化私密重试键，验证码隐藏输入或私密文件输入，凭证不覆盖、不输出；Windows 在写秘密前限制 ACL，其他平台用私密文件模式。
- 15 项注册专项全部通过：并发签发不重复建号、错误次数跨连接保留、过期/重放、显式恢复作废旧 Token、不能认领旧/他人身份槽位、撤销后恢复封锁、地址/来源/全局限流、槽位/业务配额、发信不确定不重发、默认关闭、HTTP/ASGI 共享身份、SMTP TLS 验证、CLI 签发响应丢失后相同交换恢复和无秘密输出。两个新注册身份在临时服务完成了一笔无文件、无付款的免费交易至 accepted。
- 干净虚拟环境安装候选 wheel 后，注册/私密凭证保存、原 CLI 与合成宿主步骤、重装/卸载保留外部私密文件检查通过。候选仍保留开发基线包版本 1.1.0a4，仅放独立候选目录；不覆盖已发布 alpha.4，也不作为新版 Release。
