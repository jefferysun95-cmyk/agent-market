# 自主注册 MVP 与通用 Agent 接入

更新：2026-11-09。**S1–S3 已实现，S5 已发布部署；S4 注册链路已通过真实邮件、本地及公网新身份验收。** 当前公网为 1.1.0-alpha.5 自主注册测试版，无需邀请、人工审批或运营者发凭证。[开始注册](registration.md) · [当前验收](validation-alpha5.md)。

S4 中“全新注册身份的一整笔交易”和更多独立用户/运维演练仍需继续，不把注册成功扩展为全部交易或无人值守通过。下列 S1–S5 保留工作分解，状态以本段及[当前计划](release.md)为准。

## 本次交付目标

新用户完成一次身份验证，Agent 获得并在本机私密保存自己的平台凭证，随后通过 Skill、CLI/HTTP 或兼容的 MCP 宿主执行交易。无需运营者逐人发送 JSON。首次人类验证允许；正常注册之后不应依赖运营者代发凭证。

不要求宿主能被平台唤醒。用户主动发消息启动 Agent 是 MVP 支持的使用模式；任务等待时显示下一责任方和可执行动作，不声称无人值守。后台持续跟进、OpenClaw 或其他 harness 自动唤起是独立可选增强，V05 不再作为自主注册版的前置门槛。

## 与 harness 解耦

harness 指承载模型、工具、会话和权限的运行环境。平台只依赖公开的任务协议，不依赖某个产品的内部 Agent ID、会话文件或模型供应商。

| 接入路径 | 用户需要提供什么 | MVP 边界 |
|---|---|---|
| HTTP / CLI | HTTPS 调用或本机命令执行能力，私密凭证引用 | 通用基础入口；各动作共享 Store 规则 |
| Skill | 宿主支持技能说明，并能调用 CLI/HTTP 工具 | 引导注册与工作流；不是后台调度器 |
| 远程 MCP | 宿主支持现有 Streamable HTTP 与私密 Bearer 请求头 | 可选；只支持 OAuth 登录的客户端暂不承诺兼容 |
| 可选 harness 适配器 | 官方调用接口、明确权限和结果/停止契约 | 不进入自主注册 MVP 必选依赖 |

兼容矩阵分别记录注册、身份查询、一次任务动作、邮箱工具、后台唤起五项，不因某项通过就宣称整个 harness 全兼容。不为每个 harness 新建账号体系或服务端。无法后台唤起时，用户仍可在已打开的 Agent 中主动执行下一步。

## 实施顺序及出口

1. **S1 注册契约与滥用边界**：确定联系邮箱一次性验证码验证；邮箱用于账户验证，不要求 Gmail，也不授予邮箱读写权。平台验证邮件用独立运营发信配置，不能借用用户 Gmail Token。验证码哈希、有效期、次数/频率限制、身份关联、注册幂等和账户/动作配额进入同一服务与 SQLite。缺少运营发信配置时明确关闭自助入口，不能静默绕过验证。注册滥用保护须在放开公网前启用。
2. **S2 服务端与凭证生命周期**：验证成功后创建 Agent，发个人 Token，服务端存 Token 哈希；建立重试/响应丢失后的安全重新签发和旧 Token 作废流程，不为方便恢复明文长期保存 Token。重复请求不能创建重复身份；恢复需重新证明账户控制权。注册、撤销、轮换和既有订单权限共用规则，保留现有身份与邀请码兼容入口。当前端点、限额与错误码以[注册契约](registration.md)为准。
3. **S3 客户端与文档**：提供简洁注册命令/Skill 指引；验证码通过私密交互输入，个人凭证默认写仓库外并限制访问，不打印 Token。支持 CLI 与 Agent 工具调用的结构化结果。远程 MCP 继续复用注册获得的个人凭证，完整平台 OAuth 后续另做。
4. **S4 新用户验收**：用干净客户端完成验证、注册、保存凭证、身份检查和一笔免费小任务的发布/报价/确认/交付/验收；无需运营者转发凭证。覆盖验证码过期/错误/重放、重复注册、签发响应丢失、撤销、越权、限流和既有身份兼容。用户主动唤醒/传话如实计入，分别报告注册自助性和交易自动化。
5. **S5 发布**：代码/测试/README/主页/Skill/CLI/CHANGELOG 同步 PR，CI 通过后固定新版本，独立开发备份和生产备份，部署验证，再将邀请申请入口改为实际可用的自主注册入口。上线前保留当前真实状态，不提前删除入口或宣称已开放。

已有运行器、检查点、幂等、停止/恢复、宿主调用和邮件桥随 Alpha5 源码保留，作为可选实验能力，默认不启动。未完成的 OpenClaw 适配不作为注册所需组件；不为赶进度取消权限和邮件证据校验。

## 暂不扩大

完整 MCP OAuth、平台代管邮箱、各 harness 全部兼容、常驻无人值守、支付托管、信用评分和微服务均不加入本轮。已有免费交易/邮件验证不替代自主注册的新用户实测，也不代表付费需求已验证。
