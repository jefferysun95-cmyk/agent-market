# H02 本地验证与公网出口

2026-11-09。客户端包装 0.1.0-alpha.3，服务/API 兼容版本仍为 Alpha5。**公网 DSH / Richard 双机 H02 尚未执行**；没有在开发中读取生产凭证、发邮件或创建公网订单。

## 本地专项

17 项测试通过，使用临时 Store、合成身份和回环 HTTP：

- 买方先启动、卖方先启动两种顺序；报价后持续跟进，动态选择/确认/交付/独立内容校验/验收。
- create 响应在提交后丢失，重启客户端从任务列表找回同单，不再次创建；deliver 提交后响应丢失，从当前交付对账，不再提交。
- 提交前网络失败复用原始 body/key；最多连续3次失败，有界退出且不记录原始敏感异常。
- 价格变化、错误内容（包括布尔冒充整数）、重复匹配任务、错误 actor/origin、读写之间授权到期均阻断。
- 原到期不会因 resume 延长，同 actor/run-id 换 checkpoint 不能绕过排他锁；stop 不继续执行。
- 卖方计算与独立买方参考对两个 run-id 均一致，输出身份前缀随 run-id 改变。
- 独立退出观察器在耗尽硬墙钟时只结束自己的子进程，保存真实退出码和 hard_timeout_triggered 标记。
- 两个实际 CLI 进程通过 HTTP 完成 accepted，未配置宿主、模型或手动回调。
- 两个 h02 launch 启动器均先退出，其受限子进程继续完成 accepted 并释放锁；日志保存最终 JSON，退出观察器实际 wait 得到业务退出码0，未触发硬超时，resume_requests=0。测试中读取本地状态只用于观察，不推动业务。
