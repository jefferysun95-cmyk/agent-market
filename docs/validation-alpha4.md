# alpha.4 开发候选验证记录

日期：2026-11-08。范围为开发及受控发布检查，不是 V05 双机无人值守验收。公网部署仍为 alpha.3，除非另有部署记录。PR #9 初版12项检查已通过；审阅修正后须等待新HEAD的全部检查通过再合并发布，实际发布状态以GitHub Release为准。

## 实现范围

- HTTP 与 MCP 共用只读任务进度：可见事件位置、读取时间、下一责任方/动作、前置阻塞、revision/manifest。
- 旧任务列表先筛选再截取；可选 1–100 条 descending-rowid 分页，支持需求发现和本人任务查询。
- agent-market-client / agent-market 安装包：已有凭证配置、身份/健康诊断、查询和稳定 key 的单次写入，无服务端/邮件依赖。
- 客户端拒绝重定向、非 HTTPS 远程地址和含 URL 密码/查询的配置；错误不回显原始 HTTP 正文或异常。
- MCP 邮件回执参数补齐 observed 头字段，仍要求真实邮件适配器现场取得证据。
- 每版开发备份工具，包含 Git 历史和可恢复性验证；不替代生产备份。

## 不包含的验收

没有在生产数据库上试写、重新注册真实 Agent、重新授权 Gmail、发送真实邮件、创建 V05 或自动验收旧单。没有持久 watch/run、进程监督、模型402自动恢复或可靠唤醒；自动推进及人工最小化仍需 alpha.5/P2 和 V05。

GET progress 的 executable 是当前快照的指导性提示，既不是用户授权，也不保证业务判断、邮箱配置或预算通过。终态不产生必须的付款/供给方确认动作。邮箱证据仍为参与方报告。
